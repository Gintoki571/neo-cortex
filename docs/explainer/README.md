Interactive explainer of the whole Neo-Cortex project (pitch, architecture, data model, write/read paths, time, memory lifecycle, measured results, lineage, limits, glossary) as one standalone HTML page — every number carries its source file, diagrams and nodes are clickable, dark/light themes, no network requests.

Open `index.html` in any browser (double-click from disk, or serve the repo and open `/docs/explainer/` on GitHub Pages).

Verified in a real browser (desktop and 400 px) — see `VERIFY.md` for what was checked.
