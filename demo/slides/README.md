# Slides

- `index.html` is the whole deck (10 slides, S0-S9): one standalone file, no network needed.
- Keys: Right/Space = next step or slide, Left = back, 0-9 = jump, F = fullscreen. `#3` in the URL opens slide 3.
- Every number comes from demo/VIDEO.md, demo/CAPTURE.md or eval/; text follows the plain-language rules in .neo/briefs/contract.md.
