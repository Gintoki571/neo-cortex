# Setup

Throwaway venv, Python 3.12, CPU-only torch (the CUDA wheel download was too slow to wait for). Versions from `versions.txt`: falkordblite 0.10.0, gliner2 2.1.0, sentence-transformers 6.1.0, torch 2.14.1+cpu, transformers 5.20.0, bm25s 0.3.13, mcp 2.3.0. Models were loaded from the local copies `gliner2.5-base-v1/` and `embeddinggemma-2/`. Machine: 12 CPUs, 15 GiB RAM, GTX 1660 Ti 6 GiB.

# GLiNER2.5 base on CPU (spike_gliner.txt, spike_gliner2.txt)

- Load 3.0 s. Per call on one paragraph: entities 123 ms, relations 144 ms, classification 122 ms, routing 79 ms.
- Entities from a session paragraph: `'person': ['Claude', 'Priya'], 'file path': ['auth/login_test.py'], 'config setting': ['SESSION_TTL'], 'lesson learned': ['always mock time in session tests'], 'date': ['2026-10-14']`. It missed "Redis session cache" and `config/ci.yaml` with bare labels; with a label description (`"config file": "path to a configuration file"`) it found `config/ci.yaml`.
- Relations: `'owns': [('Priya', 'auth service')], 'approved': [('Priya', 'change')]`, plus one wrong pair `'fixed by': [('test', 'Claude')]`. Relations need a confidence threshold and must keep source spans.
- Short labels misroute: "who approved the session TTL change and why?" → `summarize topic`, and an episode was typed `semantic fact`. Descriptive labels fixed both: routing 5 of 6 correct with confidence (`0.7986` owner question, `0.9999` temporal, `0.9383` how-to); the miss ("how is X related to Y") went to the owner label at `0.674`.
- Plan impact: GLiNER is usable for extraction, typing and routing, but labels must be descriptive and checked on a gold set. Route with soft channel weights, not hard switches.

# EmbeddingGemma 2, text-only (spike_embed.txt)

- `config_kwargs={"vision_config": None, "audio_config": None}` loads 271M params in 1.6 s. Even text-only, the processor import needs `pillow` and `torchvision` installed (two ImportErrors in the run).
- 64 short documents in 7.08 s on CPU (about 110 ms each). Use the GPU for bulk ingest.
- `prompt_name="SearchQuery"` works. Similarity: relevant 0.794, unrelated 0.55. The gap is real but the floor is high, so do not threshold raw cosine; rank and fuse.
- Prompts available include `query, document, Classification, Clustering, CodeRetrieval, FactChecking, QuestionAnswering, ...`.

# MCP Python SDK 2.3.0 (spike_mcp.txt)

- `mcp.server.fastmcp` no longer exists: "This is mcp 2.x, where FastMCP was renamed to MCPServer (from mcp.server.mcpserver import MCPServer)".
- `MCPServer.run(transport: Literal['stdio', 'sse', 'streamable-http'])`; decorated tools get JSON schemas from type hints, and `call_tool` returns text plus `structured_content`.
